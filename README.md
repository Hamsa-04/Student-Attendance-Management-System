# 🎓 Student Attendance Management System

A web-based Student Attendance Management System developed using **PHP** and **MySQL**. The system helps administrators manage student records and attendance efficiently.

## 📌 Features

- 🔐 Admin Login
- ➕ Add Student
- 👨‍🎓 View Students
- ✏️ Edit Student
- 🗑️ Delete Student
- 📝 Mark Attendance
- 📅 View Attendance
- 🚪 Logout
- 💾 MySQL Database Integration

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- XAMPP
- Git & GitHub

## ⚙️ Installation

1. Install XAMPP.
2. Copy the project into the `htdocs` folder.
3. Start Apache and MySQL.
4. Import `attendance_db.sql` into phpMyAdmin.
5. Open:

```
http://localhost/Student-Attendance-Management-System
```
